VS Code的名气是早就打出来的，但在各大教程中好像并未推荐大家一上来就用VS code。 原因就是这玩意不像其他轮椅编辑器那样具有开箱即用的属性。所以本文便是先带大家感受一下调教这小东西的美好与乐趣（

## 三篇避坑笔记

### ① [C++ 输出中文乱码？加一个编译参数就好](/article/vsc-zhongwen-luanma)

代码里写 `std::cout << "你好"`，控制台却是一堆乱码。不用改系统、不用动编码，只给 g++ 加一个 `-fexec-charset=GBK`。~~感受一下GB（国标）的力量？~~

### ② [让 Ctrl+F5 弹出独立终端跑 C++](/article/vsc-zhongduan)

VS Code 默认把结果输出在集成终端里，看着挤，也没法给程序输入。用 `launch.json` 换成真正的黑窗口。 ~~我觉得主要是装逼用的~~

### ③ [让滚动和光标更顺滑](/article/vsc-pinghua)

三行 `settings.json`，滚动手感和光标动画立刻不一样——属于用过就回不去的那类设置。~~德芙般的丝滑~~~

## 环境

三篇都基于 **Windows + VS Code + MinGW-w64（g++ / gdb）**，配置文件直接写在正文里，复制即可。
