# 艺术理念

> 这份文档回答一个问题：**在这个站里，什么是对的，什么是错的。**
> 写文案、做页面、加功能之前先过一遍，比事后返工便宜。

---

## 一、一句话版本

时间是一条单行道，人被推着向前却未必知道方向；迷惘是底色，但底色之上仍有温柔而顽强的追寻。
**云不是自我的比喻，而是被追逐的宾语。**

三个意象各司其职：

| 意象 | 对应什么 | 在站里的落点 |
| --- | --- | --- |
| **单行道** | 时间不可回头 | 时间线页、上一篇/下一篇、侧栏两侧的路面 |
| **云** | 追而不得、飘忽却不失方向 | 分类标签、程序化封面、页面留白 |
| **庇护所** | 允许疲惫、迷失、停顿 | 树洞、留声机、404 未来的位置 |

---

## 二、角色

**白发猫耳娘，是同行者，不是英雄。**

- 银白长发、猫耳、宽松卫衣
- 眼神**迷惘但温柔平静**——不是"元气"，不是"微笑营业"
- 姿态：并肩走，不是引路；不举旗、不呐喊
- 她出现的地方：横幅、关于页、侧栏头像
- 她**不应该**出现的地方：促销位、功能按钮上、任何"欢迎使用"式的界面

---

## 三、语气规范

### 该这样说话

| 场景 | 站内真实文案 |
| --- | --- |
| 站点描述 | 迷路也没关系，这里可以坐下歇歇。 |
| 首屏 | 单行道上，云在飘，你在走。 |
| 页脚 | 来处已不可考。去处亦不必知。唯行路本身，尚在脚下。 |
| 树洞空状态 | 说点什么，云在听。 |
| 树洞出错 | 风把这句话吹散了，再试一次好吗。 |
| 单行道收束 | 路还长，慢慢走。 |

### 不该这样说话

| 反例 | 为什么不行 |
| --- | --- |
| "欢迎来到我的博客！" | 社交平台的招呼腔 |
| "快来听歌吧～" | 召唤式营销 |
| "今天也要元气满满哦！" | 强行积极，与"可以疲惫"直接冲突 |
| "记录美好生活" | 把内容工具化 |
| "关注我，一起成长" | 增长话术 |
| 任何感叹号连用 | 情绪过载 |

### 三条硬规则

1. **不评判**：不说"你应该"，只说"你可以"。
2. **不给解法**：树洞只陪伴、只回应情绪，不出主意。
3. **不用命令语气**：不用"请""立即""马上"。

## 四、视觉语言

### 4.1 色彩（`app/globals.css` 的 `:root`，改这里即全站生效）

| 令牌 | 值 | 用途 | 禁忌 |
| --- | --- | --- | --- |
| `--cream` | `#f5f0eb` | 背景起点 | — |
| `--sand` | `#d9d0c5` | 装饰线 | — |
| `--ink` | `#4a4a4a` | 正文 | — |
| `--ink-sub` | `#6e6e6e` | 辅助文字 | 对比度需 ≥ 4.5:1 |
| `--ink-mute` | `#9c9c9c` | 轻声的小标题 | 不用于正文 |
| `--ink-faint` | `#b5b5b5` | 纯装饰 | 不承载信息 |
| `--mist` | `#b5c4c9` | 冷色点缀 | **禁止用于正文** |
| `--amber` | `#e8d5c4` | hover / 点缀 | 不做大面积底色 |
| `--accent` | `#9c8fd0` | 按钮、进度条 | 不做正文色 |
| `--link` | `#6f5b95` | 链接 | — |
| `--ink-hero` | `#4d4266` | 首屏标题 | 仅首屏 |

**整体调性**：暖米底色 + 冷色点缀 + 一处薰衣草紫。低对比、低饱和、无纯黑纯白。

### 4.2 字体

| 用途 | 字体 |
| --- | --- |
| 正文 / UI | Inter（细字重 300–500） |
| 标题 / 诗性文字 | 思源宋体 Noto Serif SC |
| 日期 / 时长 / 计数 | 等宽字体（`font-mono`） |

数字用等宽是本项目的一个小心思：让"2026.09.01"这类信息显得**像里程桩上的刻字**，而不是普通正文。

### 4.3 质感

- **毛玻璃**：`rgba(255,255,255,.6)` + `blur(16px)`，圆角 24px
- **虚线**：时间轴用 2px 虚线，模拟路面标线
- **阴影极轻**：`0 2px 16px rgba(0,0,0,.04)`，hover 才到 `.08`
- **动效**：0.2–0.3s，只做淡入与轻微上浮，**不做弹跳、不做旋转**

### 4.4 图像

- 横幅用实景/插画，允许全屏铺满
- 文章无封面时**程序化生成**：冷灰蓝天 `#c9d9e3 → #e2ebf0 → #f6efe6`，云层用 `#a8bfcc`，云缝暖光 `#efb887`
- 侧栏两侧是同一张单行道图的两个切片（左 22% / 右 48%），合起来是一条完整的路

### 4.5 构图原则

1. **留白优先**：宁少勿多，宁可空着也不填满
2. **分区靠留白和卡片边界，不靠满宽色带**（踩过坑，见第七节）
3. **一张页面只有一个视觉重心**
4. **居中堆叠要节制**：标题 + 副标题 + 控件三段式，连续重复三段就会像 PPT

## 五、结构即隐喻

```text
云端 /           封面：只有一张图与一个入口
单行道 /clouds   时间正序排开的文章 = 一条只能向前的路
文章 /article/…  路上的一个里程桩
侧栏             路的两侧（同一张图的左右切片）
```

导航用词也遵循这个隐喻：**云端 → 单行道 → 文章**，不是"首页 → 博客 → 详情"。

## 六、明确的禁忌

| 类别 | 具体表现 |
| --- | --- |
| 戏谑 / 嘲讽 | 玩梗、玩谐音、"哈哈哈"式文案 |
| 摆烂 | "写不出来就算了""随缘更新"式自嘲 |
| 过度欢快 | 感叹号、emoji 堆砌、荧光色 |
| 英雄主义 | "坚持就是胜利""你也可以做到" |
| 增长黑客 | 阅读数、点赞数、热门排行、订阅弹窗、打卡 |
| 视觉噪音 | 满宽硬色带、高饱和主色、多种圆角混用、装饰性动画 |

## 七、决策记录（这个站做过的取舍）

| 决策 | 理由 |
| --- | --- |
| 删掉「迷途集 / 单向书」两个板块 | 两个并列的文集削弱了"一条路"的隐喻，合并成统一时间线 |
| 拒绝满宽色带分段 | 试过 `#eef2f5`/`#ece1d6` 三段色带，在柔和渐变底上像三块地板，比原来更糟。改为留白 + 卡片边界分区 |
| 封面程序化生成 | 没有配图时不能让页面空着，但也不能用随机图库破坏调性 |
| 播放器提到根布局 | "看文章时也能听歌"是体验需求，也贴合"声音是另一种云"（云应该跟着你走） |
| 文章入口不用新窗口 | 同窗口更连贯；新窗口会让人失去"在路上"的连续感 |
| 数字用等宽 | 让日期像里程桩刻字 |
| 侧栏用单行道照片 | 把核心理念从文案变成可见之物 |

## 八、自检清单

### 写完一段文案

- [ ] 有没有"你应该""快来""立即"
- [ ] 有没有感叹号
- [ ] 是不是在给结论、给鼓励、给解法
- [ ] 删掉一半字数，意思还在吗

### 做完一个页面

- [ ] 视觉重心是不是只有一个
- [ ] 有没有连续三段居中堆叠
- [ ] 空白是"透气"还是"空荡"
- [ ] 颜色是不是都来自令牌，没有临时色值
- [ ] 换到手机上，第一屏还能看懂吗
